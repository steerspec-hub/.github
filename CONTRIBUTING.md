# Contributing to SteerSpec Hub

Thanks for your interest. SteerSpec Hub is in early development and we welcome feedback, bug reports, and ideas.

## Where to contribute

- **OWASP ASVS realm** → [strspc-hb-std-owasp-asvs](https://github.com/steerspec-hub/strspc-hb-std-owasp-asvs)
- **Org defaults and profile** → [.github](https://github.com/steerspec-hub/.github)
- **SteerSpec itself** (rule format, engine, CLI) → the [SteerSpec](https://github.com/SteerSpec) organization

A realm's rules are generated from the standard's own release, so a wrong clause is fixed in the generator or reported upstream to the standard's authors, never by editing rule files by hand.

## How to contribute

1. Open an issue first to discuss the change you'd like to make.
2. Fork the relevant repo and create a branch from its default branch, `main`. That is also where your pull request should land.
3. Make your changes, then open a pull request with a clear description.

Commit messages and pull request titles follow [Conventional Commits](https://www.conventionalcommits.org) (`type(scope): subject`); every repository checks them in CI. Where a repo has a `CONTRIBUTING.md`, an issue form, or a pull request template of its own, follow that; it wins over this page.

## Code of conduct

Be direct, be constructive, be kind. The long version is the [Contributor Covenant](CODE_OF_CONDUCT.md), which applies across every SteerSpec Hub repository.

## Security

Never report a vulnerability as a public issue — use the private channel described in the [security policy](SECURITY.md).
